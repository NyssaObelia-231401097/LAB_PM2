📌 Project Description
AnimeVerse adalah aplikasi katalog dan eksplorasi anime berbasis Flutter yang memudahkan pengguna untuk mencari, menelusuri, dan menyimpan daftar anime favorit.
Aplikasi ini terintegrasi dengan Firebase untuk autentikasi pengguna dan penyimpanan data favorit di cloud sehingga setiap user hanya bisa mengakses datanya sendiri.
